## O problema

Saldo de conta não responde sozinho quanto está disponível para gastar. Faturas,
reservas, metas, dívidas e investimentos mudam a leitura — e planilhas costumam
misturar esses conceitos até dois números corretos parecerem incompatíveis.

O Gestor Financeiro trata lançamentos como ledger e deriva uma visão coerente de
caixa, obrigações e patrimônio. A mesma regra serve dashboard, relatório, web e
mobile.

<Callout variant="warning">
  Métrica financeira precisa de definição, não apenas de fórmula. Horizonte,
  liquidez e origem do lançamento fazem parte do significado do número.
</Callout>

## Arquitetura

O backend Spring Boot expõe uma API versionada sobre PostgreSQL. Serviços de
domínio concentram reconciliação, faturas, metas, recorrências, orçamentos e
investimentos. React atende a operação detalhada no desktop; React Native leva
as rotinas frequentes ao celular.
